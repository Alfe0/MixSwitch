# MixSwitch — دليل عربي

برنامج للتحكم بالصوت العام وصوت التطبيقات والتبديل السريع بين أجهزة الإخراج في Windows، مبني بلغة Rust باستخدام واجهات Windows الأصلية.

**أول إصدار عام:** `v1.0.0` — أما `v4.2` فهي تسمية لنسخة تطوير داخلية للواجهة.

## الاستخدام

- افتح/أغلق الميكسر باختصار `Page Down` (يمكن تغييره من الإعدادات).
- بدّل جهاز الصوت باختصار `End` (يمكن تغييره).
- اضبط الصوت لكل تطبيق، واستخدم أيقونته للكتم/إلغاء الكتم.
- غيّر اسم الجهاز الظاهر داخل البرنامج دون تغيير اسم جهاز Windows الفعلي.
- شغّل البرنامج مع Windows اختياريًا من الإعدادات.

## إذا كنت مستخدمًا

حمّل `MixSwitch.exe` من **Releases**، ضعه في مسار دائم قابل للكتابة، وشغّله مباشرة. لا يحتاج إلى مثبت. قد يحتفظ البرنامج بإعداداته في `%APPDATA%`.

## إذا كنت صاحب المشروع وتريد بناء EXE

المتطلبات: Windows x64، وRust/Cargo، وأدوات Visual Studio C++ Build Tools الخاصة بـ MSVC.

1. أغلق MixSwitch الحالي من التراي.
2. شغّل `PACKAGE_RELEASE.bat` داخل مجلد المشروع.
3. بعد نجاح البناء ستجد `dist\MixSwitch.exe` و`dist\SHA256SUMS.txt`.
4. شغّل النسخة الناتجة واختبرها قبل رفعها إلى GitHub.

## عبر GitHub Actions

ارفع المشروع إلى مستودع GitHub في الفرع `main`. ستعمل مهمة `Build MixSwitch for Windows x64` تلقائيًا أو عند تشغيلها يدويًا من صفحة **Actions**. بعد نجاح البناء ستجد أثرًا قابلاً للتنزيل باسم `MixSwitch-Windows-x64` يحوي EXE وSHA-256.

إذا دفعت وسم الإصدار `v1.0.0` إلى GitHub، سيبني النظام الملف ويجهز **مسودة Release** تلقائيًا، ولن يعلنها للعموم حتى تختار **Publish release** بنفسك.
