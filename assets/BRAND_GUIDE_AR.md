# MixSwitch — Brand Colors

| الدور | القيمة | الاستخدام |
| --- | --- | --- |
| Primary Cyan | `#23D1C9` | السلايدرات والأزرار التفاعلية |
| Accent Blue | `#27AAED` | جزء من التدرج الأزرق في الشعار |
| Mint | `#8BEE87` | أول التدرج في الشعار / إشارة الحالة الإيجابية |
| Background | `#131B27` | المساحات الرئيسية |
| Header | `#1E2632` | الهيدر |
| Card | `#293647` | البطاقات |
| Text | `#F3F8FC` | النصوص |
| Muted Red | `#FA6174` | حالة كتم الصوت والأفعال الخطرة، لا تستبدل بالأخضر |

الشعار المحسن مستوحى من صور المستخدم، لكن تم إعادة رسمه في SVG لتقليل التوهج وضمان وضوحه بحجم 16 بكسل، وهو ليس نسخة مطابقة بكسلًا ببكسل للصورة المصدرية.
