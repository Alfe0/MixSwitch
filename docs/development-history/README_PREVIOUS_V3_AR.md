# MixSwitch — UI Polish / Compatibility v3 (مصدر للتجربة)

هذا تحديث **مبني على نسخة Fluid Identity v2** التي نجحت في التشغيل عند المستخدم. أبقينا إصدار التطبيق الداخلي `v1.0.0` كي لا ندّعي إطلاق نسخة مستقرة جديدة قبل اختبار Windows. **لم نغيّر src/audio.rs مطلقًا**.

## ما تم تنفيذه في الكود

- **الميكسر:** أرقام الصوت 24px عوض 21px، تقليل عرض السلايدر، تكبير المقبض قليلًا وإبقاء قيمة الصوت مرئية حتى أثناء الكتم، مع رمز كتم جديد واضح 30px.
- **Mute:** اللون الأحمر الداكن `#B84258` موحّد بين المقبض والشريط ورمز الكتم. إضافة طبقة شفافة تخفّف ظهور أيقونة التطبيق عند الكتم، من دون تعديل أيقونة التطبيق الأصلية.
- **التراي:** تصميم مستقل مبسط لأيقونة التراي الصغيرة (من نفس هوية الأخضر/التركوازي/الأزرق)، وتضمين أحجام محسنة 16/24/32 في ICO. حجم مساحة أيقونة النظام نفسه تحدده Windows.
- **الإعدادات:** توضيح تسجيل الاختصارات بالنص وبتحديد الأزرار؛ فصل كل جهاز في صف بخلفية وحدود أوضح؛ زر Rename مستقل مع زر تغيير أيقونة الجهاز. زر تشغيل تلقائي اختياري `Launch at Windows Startup`؛ الافتراضي OFF.
- **أسماء الأجهزة:** يظهر الاسم المختصر تلقائيًا عند وجود الاسم الكامل بالشكل `pc38x (Fosi Audio K5 Pro)` أو `M60 (EDIFIER M60)`. ويمكن تخصيص أي اسم من زر Rename. الأسماء الجديدة تحفظ بمعرّف جهاز الصوت في `device_aliases` داخل `%APPDATA%\MixSwitch\mixswitch_config.json`؛ لا يتم تغيير اسم Windows أو معرّفات الجهاز أو محرك الصوت.
- **لوحة الإعدادات:** التمرير بعجلة الماوس عندما يضيق ارتفاع الشاشة أو تزيد الأجهزة؛ لا تتلقى الصفوف المخفية نقرات خطأ على الهيدر. تم إبطاء تحديث الإعدادات فقط إلى 600ms بدل 150ms لخفض العمل غير الضروري، بينما يبقى تحديث الميكسر 150ms للحفاظ على الاستجابة ومؤشر الذروة.
- **About:** تكبير الخط والعناصر، وإزالة ادعاء مقدار RAM غير مقاس.
- **إشعار الجهاز:** حجم أصغر (330×84)، خط اسم جهاز أكبر، شفافية أكثر (alpha=218)، وإظهار الاسم المخصص بعد التبديل بالاختصار/قائمة التراي.
- **النشر:** `BUILD_EXE.bat` لا يزال يبني `MixSwitch.exe` محمولًا واحدًا. يوجد ملف GitHub Actions اختياري لتوليد EXE على Windows 64-bit.

## طريقة الاستخدام

1. احتفظ بنسخة احتياطية من MixSwitch.exe الذي يعمل عندك.
2. فك هذا ZIP في مجلد جديد، ولا تدمجه مع ملفات النسخة المعتمدة.
3. أغلق MixSwitch الحالي من التراي.
4. شغّل `BUILD_EXE.bat` على Windows مع Rust/MSVC مثبتين. سيظهر MixSwitch.exe بجانب ملف البناء **بعد نجاحه**.
5. اختبر النسخة قبل استبدال إصدارك الحالي.

**Rename:** Settings > PLAYBACK DEVICES > Rename بجانب الجهاز. اكتب الاسم، ثم Enter للحفظ وEsc للإلغاء. لإزالة الاسم المخصص: افتح Rename ثم Ctrl+A وEnter (لتصفير الحقل). الاسم الأصلي ظاهر بالسطر الثاني.

**Startup:** Settings > GENERAL > Launch at Windows Startup > ON. ينشئ إدخالًا للمستخدم الحالي فقط في `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` باستخدام `reg.exe` النظام، دون صلاحية Administrator. عند التشغيل مع Windows يظل البرنامج في التراي ولا يفتح الميكسر. لإلغاء التسجيل اختر OFF. الإعداد **لا يُفعّل بدون اختيار المستخدم**.

**مهم للنسخة المحمولة:** إذا فعّلت Startup ثم نقلت `MixSwitch.exe` إلى مجلد مختلف، أوقف Startup وأعد تشغيله من الإعدادات كي يُحفظ المسار الجديد.

## ما لم نتدخل فيه

- Core Audio / COM / صوت التطبيقات / تبديل جهاز الإخراج (`src/audio.rs`).
- طريقة فتح وإغلاق Flyout بالاختصار والنقر الخارجي، أو التبديل من قائمة التراي.
- طريقة تفعيل اختيار الأجهزة وكتم الأصوات، واختصارات المستخدم المحفوظة.
- اعتماد مكتبات Rust أو إطار واجهة ثقيل إضافي.

## المتبقي قبل الإصدار المستقر (أهداف، وليست إنجازات مُختبرة)

- **البناء والاختبار على Windows 10 و11 x64**. لا توجد عدة Rust وWindows للتشغيل في بيئة إعداد الملف الحالية؛ **لم يتم تأكيد نجاح cargo build أو EXE تشغيلًا**.
- تحقق التوافق في 100%, 125%, 150%, 200% DPI، والشاشتين، وتبديل الشاشات، والحالات ذات 4–10 أجهزة. Per-Monitor DPI v2 مستعمل، لكن بعض قياسات الواجهة لا تزال بوحدات بكسل ثابتة؛ هذا يحتاج فحصًا وتحسينًا مستقلًا.
- تحقق من Alias مع لوحات مفاتيح عربية / IME؛ إدخال الاسم حاليًا بسيط داخل نافذة الرسم، وليس محرر نص Windows الكامل.
- تحقق من سلوك Startup عندما يعطل المستخدم تشغيل التطبيقات من **Windows Settings**؛ والتحقق من نقل ملف EXE. التسجيل اختياري وليس فرضًا على المستخدم.
- فحص ظهور Mica في إصدار Windows المستهدف؛ ظهور Blur الحقيقي ليس مضمونًا في GDI layered windows. يوجد fallback داكن صالح للأجهزة الأقل دعمًا.
- قياس مقاييس الأداء على جهاز مستخدم حقيقي: **الرام أثناء الخمول <15MB هدف تقريبي وليس وعدًا**، CPU قريب من 0% عند الإخفاء، EXE صغير بقدر الإمكان (كان الهدف <3MB)، واستجابة الفتح <100ms. لا يمكن توثيق أرقام دون قياسات.
- اختبار ملامسة السلايدر ومناطق النقر والميوت والـ Hover وخيارات التراي وفشل تسجيل الاختصارات. التأكد من الحالة بعد إعادة تشغيل Explorer.
- يمكن لاحقًا إضافة إعداد لتبديل **MixSwitch Accent / Windows Accent** إذا رغبت؛ هذه النسخة ما زالت تستخدم لون الهوية التركوازي الثابت.
