# MixSwitch v1.0.0 — First public release

MixSwitch is a small native Rust/Win32 volume mixer and playback-device switcher for Windows x64.

### Highlights

- Compact dark tray flyout with master and per-application audio controls.
- Real-time audio peak indicators, including while dragging a volume slider.
- Per-application mute controls and audio output device switching.
- Global hotkeys and configurable included playback devices.
- Local aliases for output devices; device icons can be changed in settings.
- Optional startup with Windows and a small device-change notification.
- Refreshed cyan/blue visual identity and embedded application resources.

### Download

Get **MixSwitch.exe** below. This is a portable executable, not an installer. Windows x64 is required.

A **SHA256SUMS.txt** file is included so you can verify the executable you downloaded.

### Important

The executable is unsigned. Windows may warn about an unfamiliar publisher. The app has been tested manually by its developer, but broad compatibility and accessibility testing are ongoing. If you find a problem, please open an issue with your Windows version and a description of how to reproduce it.
